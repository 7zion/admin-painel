# Site Images

Use this folder for fixed site images such as banners, logos, hero backgrounds, and decorative media.

Naming rules:
- Use kebab-case names without spaces or accents.
- Prefer `.webp` for banners and backgrounds.
- Use `.png` or `.webp` for transparent logos.
- Reference files from React with absolute public paths, for example: `/images/banner-home.webp`.
- Do not use external hosts for essential layout images.
